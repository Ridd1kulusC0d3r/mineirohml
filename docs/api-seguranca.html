    API local e segurança

    Endpoints, variáveis de ambiente e as proteções que impedem o servidor de virar um scanner aberto.

    POST /api/osint/verifyuma consulta de detector
    POST /api/osint/variantsvariantes de username (Jaro-Winkler)

    POST /api/osint/avatar-hashdHash perceptual de avatar

    Proteções do servidor

    • URL só do detector. O servidor nunca sonda uma URL inventada pelo cliente: ela precisa casar com o urlPattern do detector.
    • DNS protegido. O IP resolvido precisa ser público no momento da conexão. Faixas privadas, loopback, link-local e de metadados de nuvem são bloqueadas, com proteção contra DNS rebinding.
    • Redirects revalidados a cada salto.
    • Rate limit por IP (token bucket), cabeçalhos de segurança e corpo limitado a 2 MB.
    • Limite por host: 4 requisições simultâneas por padrão.

    Variáveis de ambiente

    VariávelEfeito
    PORTporta (padrão 3000)
    HOSTendereço de escuta. Na instalação por pip é 127.0.0.1
    MINEIRO_DBcaminho do SQLite (padrão data/mineiro.sqlite)
    MINEIRO_PUBLIC=1modo de instância pública (veja abaixo)
    MINEIRO_TRUST_PROXY=1confia no proxy reverso para o IP do cliente
    MINEIRO_HOST_CONCURRENCYmáximo de requisições por host (padrão 4)
    MINEIRO_CACHE_TTL_MSvalidade do cache de resultados (padrão 5 minutos)
    HOSTendereço de escuta. Padrão 127.0.0.1; a imagem Docker usa 0.0.0.0
    Por padrão o servidor escuta só em 127.0.0.1. A imagem Docker define HOST=0.0.0.0. Fora de contêiner, só use HOST=0.0.0.0 se quiser acesso pela rede.

    Modo de instância pública

    Com MINEIRO_PUBLIC=1, o servidor deixa de usar chaves guardadas nele, desativa persistência e o hash de avatar, e aplica limites mais baixos. Assim uma instância compartilhada não vira scanner aberto nem base de consultas.

    Implantação

    Para uso local, pip. Para servidor persistente, Docker (imagem Node 22, npm ci, usuário não root, healthcheck). Para URL pública, uma plataforma de contêiner gerenciada atrás de HTTPS. O Colab serve para demonstração, não para produção.
