    Detectores e Registry

    Como o catálogo de 985 detectores é mantido, validado e estendido.

    O que é o Registry

    É o catálogo de plataformas. Na v1.7 são 985 detectores catalogados, 984 escaneáveis. Cada um recebe categoria, tipo de site, confiabilidade do detector, nível de confiabilidade, status de proveniência, status de licença e checagens de evidência opcionais.

    Parte do catálogo histórico está marcada legacy-audit-required: cobertura existe, auditoria independente ainda não. Trate esses resultados com mais cautela.

    Detectores declarativos

    Em mineiro-py/src/mineiro/data/declarative.json (e registry/detectors/*.json na versão Node), cada detector declara regras de presença e ausência, handles-canário (um que existe e um que não pode existir), data de verificação e fonte. Hoje o arquivo core.json traz 3 deles: Codeberg, DEV e Keybase.

    { "id": "codeberg",
  "present": [{ "type": "status", "codes": [200] }],
  "absent":  [{ "type": "status", "codes": [404] }],
  "canary": { "present": "forgejo", "absent": "zqx9q8w7e6r5t4y3u2" },
  "lastVerified": "2026-10-02",
  "source": "own observation: ..." }

    Um workflow semanal de saúde (detector-health) roda os canários e abre uma issue quando um detector deriva.

    Comandos de validação

    ComandoFaz
    mineiro registry validatevalida os 985 detectores e os declarativos
    mineiro registry statsestatísticas por categoria e confiabilidade
    mineiro registry list --category developerlista detectores de uma categoria
    npm run detectors:health (versão Node)roda os canários contra os sites reais; ainda não portado para Python

    Não ajuste um detector só para o teste passar. O validador existe para impedir catálogo quebrado em silêncio.

    Adicionar um detector

    1. O endpoint precisa ser público.
    2. Documente a fonte, a licença, a data de verificação e o mantenedor.
    3. Informe handles-canário.
    4. Inclua um teste. Importações grandes sem rastreio não entram.

    Registry-only

    Alguns detectores ficam só no registro: servem à taxonomia e à documentação, mas não têm URL pública estável para scan direto.
