    Instalação

    Três caminhos até o primeiro scan. Escolha um e faça um passo por vez.

    Qual caminho?

    CaminhoPrecisa deBoa escolha quando
    pipPython 3.10+você quer só usar a ferramenta
    ColabConta Google e navegadornão quer instalar nada
    Código-fontePython 3.10+quer rodar os testes ou contribuir

    Caminho 1 · pip

    O pacote mineiro (~80 kB, só depende do httpx) é instalado direto do repositório.

    python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install "mineiro @ git+https://github.com/Ridd1kulusC0d3r/mineirohml.git#subdirectory=mineiro-py"
mineiro scan forgejo --preset quick

    Os presets são quick (19 sites), standard (49, com Evidence Engine e baseline) e full (984, em duas fases). Os casos ficam em ~/.mineiro.

    mineiro scan forgejo --lang pt --out relatorios/ --format html,markdown,json,stix
mineiro registry validate   # diagnóstico do registry

    Caminho 2 · Google Colab

    O notebook oficial instala o pacote Python e desenha a interface dentro da própria célula: não há servidor, porta nem link de proxy (sem IA e sem chaves). Abrir no Colab. Rode as células na ordem e use apenas um identificador que você esteja autorizado a pesquisar.

    Caminho 3 · Código-fonte

    git clone https://github.com/Ridd1kulusC0d3r/mineirohml.git
cd mineirohml/mineiro-py
pip install -e ".[dev,notebook]"
pytest

    Pede Python 3.10 ou superior. A versão Node/React original continua em mineiro-tool/ como referência.

    Verificar a instalação

    • mineiro --version informa a versão.
    • mineiro registry validate confere os 985 detectores.
    • Pelo código-fonte: pytest.

    Lançadores de duplo clique

    A raiz do repositório original traz lançadores para quem prefere não usar o terminal: Iniciar-Mineiro.bat (Windows), Iniciar-Mineiro.command (macOS) e iniciar-mineiro.sh (Linux), além do COMECE-AQUI.md. Consulte esse arquivo para o passo a passo deles.
