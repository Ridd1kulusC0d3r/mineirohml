    Instalação

    Três caminhos até a interface. Escolha um e faça um passo por vez.

    Qual caminho?

    CaminhoPrecisa deBoa escolha quando
    pipPythonvocê quer só usar a ferramenta
    ColabConta Google e navegadornão quer instalar nada
    Código-fonteNode.js 22+quer rodar os testes ou contribuir

    Caminho 1 · pip

    O README indica pip install mineiro-osint. Enquanto o pacote não estiver publicado no PyPI, instale pelo wheel do release v1.7.0.

    python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install https://github.com/Ridd1kulusC0d3r/Mineiro-OSINT-Extractor/releases/download/v1.7.0/mineiro_osint-1.7.0-py3-none-any.whl
mineiro

    A interface abre em http://127.0.0.1:3000, acessível só na sua máquina. Os dados ficam em ~/.mineiro.

    mineiro --check   # diagnóstico do ambiente

    Caminho 2 · Google Colab

    O repositório traz um notebook de inteligência de username. Abrir no Colab. Rode as células na ordem em que aparecem e use apenas um identificador que você esteja autorizado a pesquisar.

    Caminho 3 · Código-fonte

    git clone https://github.com/Ridd1kulusC0d3r/Mineiro-OSINT-Extractor.git
cd Mineiro-OSINT-Extractor
npm ci --no-audit --no-fund
npm run dev

    Pede Node.js 22 ou superior. A interface abre em http://localhost:3000.

    Verificar a instalação

    • GET /api/health informa versão e status.
    • mineiro --check roda o diagnóstico na instalação por pip.
    • Pelo código-fonte: npm test, npm run check e npm run detectors:health.

    Lançadores de duplo clique

    A raiz do repositório original traz lançadores para quem prefere não usar o terminal: Iniciar-Mineiro.bat (Windows), Iniciar-Mineiro.command (macOS) e iniciar-mineiro.sh (Linux), além do COMECE-AQUI.md. Consulte esse arquivo para o passo a passo deles.
