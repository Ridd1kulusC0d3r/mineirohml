    Solução de problemas

    O que dá para verificar sozinho antes de pedir ajuda.

    Seção em construção. O guia detalhado de problemas do repositório original ainda não foi portado para cá. Veja o SUPPORT.md.

    Checklist rápido

    1. Rode mineiro --check (pip) ou consulte GET /api/health para ver versão e status.
    2. Pelo código-fonte, confirme Node.js 22 ou superior e rode npm ci --no-audit --no-fund de novo.
    3. Rode npm test, npm run check e npm run detectors:health para separar problema local de problema de detector.
    4. Confirme que a porta 3000 está livre.

    Resultado inconclusivo

    Endpoints protegidos ficam inconclusivos de propósito: o Mineiro não tenta vencer CAPTCHA nem controles de acesso. Trate como lacuna, não como ausência.

    Rate-limited

    Candidatos rate-limited entram na fase 2 do Full. Espere antes de repetir e evite varreduras amplas sem necessidade.
