    Solução de problemas

    Sintoma, causa provável e correção. Verifique o básico antes de abrir uma issue.

    Diagnóstico rápido

    python --version      # precisa ser 3.10 ou superior
mineiro --version
mineiro registry validate
pytest                # pelo código-fonte

    Problemas comuns

    SintomaCausa provávelCorreção
    mineiro: command not foundPacote não instalado neste ambienteAtive o ambiente virtual e rode o pip install de novo
    Todos os resultados com error e CERTIFICATE_VERIFY_FAILEDRede com inspeção TLS (certificado próprio)Aponte MINEIRO_CA_BUNDLE (ou SSL_CERT_FILE) para o certificado da sua rede. Não desligue a verificação
    error: Port not allowed / Non-public addressA guarda anti-SSRF recusou o alvoÉ esperado para localhost, IPs privados e portas fora de 80/443
    Muitos UNCERTAINProteção de borda ou rate limitReduza o escopo e espere. Trate como lacuna, não como ausência
    Muitos timeoutsRede lenta ou concorrência altaUse Quick ou Standard
    FOUND parece falsoSoft-404 ou regra fracaConfira a Evidence Matrix e a URL final
    mineiro verify acusa MISMATCHO arquivo foi alterado depois da exportaçãoExporte de novo. O SHA-256 prova integridade do conteúdo, não autoria
    Full demoraCobertura amplaUse Full só quando a cobertura realmente importa

    Atualizar no Colab

    Use Runtime → Restart session e rode a célula 1 · Instalar de novo: o pip baixa a versão mais recente do repositório. Não há servidor nem porta, então não há erro de proxy.

    Registry inválido

    Rode mineiro registry validate e mineiro registry stats. Não corrija um detector só para o teste passar.

    Ao abrir uma issue

    Informe a versão do Mineiro, o sistema (ou Colab), a versão do Python, o preset, a mensagem de erro e os passos mínimos para reproduzir. Não publique tokens, cookies, credenciais nem dados pessoais.
