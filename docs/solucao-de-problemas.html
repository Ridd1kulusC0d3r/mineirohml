    Solução de problemas

    Sintoma, causa provável e correção. Verifique o básico antes de abrir uma issue.

    Diagnóstico rápido

    node --version      # precisa ser 22 ou superior
npm run registry:validate
npm run lint
mineiro --check     # instalação por pip

    Também vale chamar GET /api/health: deve devolver a versão e status saudável.

    Problemas comuns

    SintomaCausa provávelCorreção
    node: command not foundNode ausenteInstale Node.js 22+
    Porta 3000 ocupadaServidor anterior ainda rodandoEncerre o processo ou use PORT=3001
    Colab: página com HTTP 500Servidor escutando só em loopback (notebook antigo)Rode de novo as células Bootstrap e Start: o notebook atual usa HOST=0.0.0.0 na VM do Colab
    Muitos UNCERTAINProteção de borda ou rate limitReduza o escopo e espere. Trate como lacuna, não como ausência
    Muitos timeoutsRede lenta ou concorrência altaUse Quick ou Standard
    FOUND parece falsoSoft-404 ou regra fracaConfira a Evidence Matrix e a URL final
    Build falhaDependência ou cacheApague node_modules e rode npm ci
    Notebook abre, UI nãoServidor não está saudávelVeja /content/mineiro-server.log e o health check
    Relatório sem SHA-256Web Crypto indisponívelUse um navegador moderno em localhost ou HTTPS
    Full demoraCobertura amplaUse Full só quando a cobertura realmente importa

    Atualizar no Colab

    Rode de novo as células Bootstrap e Start Mineiro: o clone é atualizado, o build é refeito e o servidor reinicia. O log fica em /content/mineiro-server.log.

    Registry inválido

    Rode npm run registry:validate e npm run registry:stats. Não corrija um detector só para o teste passar.

    Ao abrir uma issue

    Informe a versão do Mineiro, o sistema (ou Colab), a versão do Node, o preset, a mensagem de erro e os passos mínimos para reproduzir. Não publique tokens, cookies, credenciais nem dados pessoais.
