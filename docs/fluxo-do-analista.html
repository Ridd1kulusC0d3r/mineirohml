    Entender

    Fluxo do analista

    Como um analista OSINT usa o Mineiro: pergunta primeiro, menor coleta que responde, evidência antes de conclusão.

    Opinião de método, não texto oficial. Serve para decidir o que fazer com a ferramenta, não para substituí-la.

    Regras de mão

    1. Escreva a pergunta antes de coletar. Sem requisito, o resultado vira lista de links.
    2. Comece pelo Quick. Suba para Standard só se a pergunta exigir evidência com hash e baseline. Full é exceção.
    3. Leia os medidores na ordem: primeiro a qualidade do sinal, depois a cobertura, depois a correlação. Um número alto sozinho não decide nada.
    4. Trate FOUND como observação. Confirmação exige um segundo sinal independente.
    5. Registre a lacuna. O que não foi encontrado e o que não foi coletado entra no relatório.
    6. Exporte o mínimo. HTML para ler, JSON para guardar. STIX só se outro sistema vai consumir.

    O que normalmente não vale o tempo

    • Repetir scans Full para ver se algo mudou. Use o Diff entre coletas.
    • Seguir todos os candidatos do grafo. Siga os que respondem à pergunta.
    • Gerar todos os formatos de exportação por hábito.
