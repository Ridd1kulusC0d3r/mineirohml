    Documentação do Mineiro

    O Mineiro é uma bancada de investigação OSINT para presença pública de usernames: evidência primeiro, correlação cautelosa e relatórios auditáveis.

    Esta é a documentação de homologação (hml) da comunidade, escrita em pt-BR. O texto de referência e a versão mais recente estão no repositório original. Em caso de diferença, vale o original.

    O que ele faz

    O Mineiro verifica superfícies públicas associadas a um identificador (um username) e transforma respostas técnicas brutas numa avaliação estruturada. Ele mantém separadas quatro coisas que ferramentas de username costumam misturar:

    1. Coleta: o que cada detector observou.
    2. Evidência: sinais, hash SHA-256, data e versão do detector.
    3. Correlação: o que sustenta uma relação entre contas.
    4. Avaliação: julgamentos, lacunas e próximos passos.
    Um resultado FOUND é uma observação. Não é prova de identidade.

    Siga a trilha na ordem. Cada passo cabe numa sessão curta.
