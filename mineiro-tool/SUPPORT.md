# Suporte

Antes de abrir uma issue:

1. consulte [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md);
2. execute `npm run registry:validate`;
3. execute `npm run lint`;
4. confirme a versão do Node.js.

Para Colab, consulte [docs/COLAB.md](docs/COLAB.md).

## Ao pedir ajuda

Inclua:
- versão do Mineiro;
- ambiente;
- versão do Node;
- preset;
- mensagem de erro;
- passos mínimos para reproduzir.

Não inclua:
- credenciais;
- cookies;
- tokens;
- chaves de API;
- dados pessoais desnecessários.

Questões de segurança devem seguir [SECURITY.md](SECURITY.md).
